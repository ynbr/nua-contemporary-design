# 現代デザイン論

名古屋芸術大学 芸術学部 芸術学科デザイン領域／2026年度後期・火曜2限・西キャンパス
担当：浅野 翔（非常勤講師）

## この講義について

19世紀以降の近代デザイン史を手がかりに、現代におけるデザインの意味と役割を考えます。デザインを「美しいものや使いやすいものをつくる技術」としてではなく、**社会・身体・技術・文化・環境・人間関係のあり方を組み替える実践**として捉えます。

前半では産業革命以降の工芸、装飾、モダニズム、機能主義、デザイン教育、消費社会、UX、サービスデザインといった基本的な流れを扱います。後半では、デザインが**誰にとっての「よさ」を前提としてきたのか**を問い直し、参加型デザイン、デザインジャスティス、トランジションデザイン、脱植民地デザイン、技術多様性、AI時代のデザインへと進みます。

歴史上の知識を暗記する講義ではありません。身近なデザインを歴史的・社会的・文化的・技術的に読み解く力を身につけることが目的です。

## 各回のレジュメ

- [第1回 デザインという近代の発明](lectures/01-what-is-design.md) — 身近な事例からデザインの意味と範囲を考える
- [第2回 産業革命による生産・工芸・生活の変化](lectures/02-industrial-revolution.md) — 「つくる人」と「かたちを決める人」は、いつ、なぜ分かれたのか

全15回の日程とテーマは[授業日程](schedule.md)にあります。レジュメは各回の授業前に公開します。

## 到達目標

1. 近代以降のデザイン史の基本的な流れを、社会・産業・技術の変化と関連づけて説明できる
2. モダンデザイン、機能主義、記号論、UX、サービスデザイン、社会デザインなどの主要概念を区別できる
3. デザインが前提とする人間像、社会像、技術観を批判的に読み解くことができる
4. デザインが包摂・排除・権力・環境・文化に関わる実践であることを指摘できる
5. 身近なデザインを複数の視点から分析し、自分の言葉で論じることができる

## 授業の進め方

毎回、次のかたちで進めます。

| 時間 | 内容 |
|---|---|
| 0–10分 | 前回のミニレポートから抜粋を紹介し、返答する |
| 10–20分 | 今日の問い（身近な事例からの導入） |
| 20–50分 | 歴史的・社会的背景 |
| 50–75分 | 事例分析と現代への接続 |
| 75–88分 | ミニレポートの記入・提出 |
| 88–90分 | 次回予告 |

**ミニレポートは授業時間内に書いて提出します。** 持ち帰りの宿題にはしません。Google Classroom から配信されるフォームに、その場で回答してください。

冒頭10分で紹介する抜粋は、すべて匿名化したうえで扱います。名前が出ることはありません。

## 生成AIの利用について

この講義では、生成AIの利用を**一律に禁止しません**。ただし、どこで使ってよく、どこで使わないでほしいかを、理由とともにはっきり示します。ルールだけを渡されて根拠がわからない状態が、いちばん学びを損なうからです。

### この講義で鍛えたい力

到達目標の3と5、つまり **「デザインが前提とする人間像・社会像・技術観を批判的に読み解き、自分の言葉で論じる」力**です。これは、資料を要約する力でも、整った文章を出力する力でもありません。**目の前のものを見て、違和感を言語化し、その違和感がどこから来ているかを歴史や社会に接続して考える**力です。

### だから、こう線を引きます

**使ってよいこと**

- 講義で出た人名・用語・年号・出来事を調べる
- 英語文献を読むための翻訳、下読み
- 自分が書いた文章の誤字脱字や表記の確認
- 考えを整理するための壁打ち、対話相手として

**使わないでほしいこと**

- **ミニレポートの本文を生成させること。** ミニレポートは授業時間内に、その場で考えたことを書いてもらうためのものです。AIに書かせた時点で、この時間は何の役にも立たなくなります。
- **期末レポートの「自分の観察と考察」にあたる部分を生成させること。** 何を事例に選び、そこに何を見たかは、あなたにしか書けない部分です。

**期末レポートには、AIの利用を申告する欄を設けます。** 何をどう使ったかを書いてください。申告したこと自体で減点することはありません。むしろ、自分が何をAIに任せ、何を任せなかったかを言語化する作業は、この講義の第14〜15回で扱う内容そのものです。

### AI検出ツールは使いません

提出物をAI検出ツールにかけることはしません。これらのツールは誤検知を避けられず、検出されたかどうかで疑いをかけることは、教える側と学ぶ側の信頼関係を壊すからです。そのかわりに、申告制と、授業時間内に書くという設計で対応します。

### 講師自身のAI利用について

このレジュメは、浅野がAI（Claude）を使って作成しています。文献の探索、構成の検討、下書きの作成に使い、内容の判断と最終的な記述は浅野が行っています。各回のレジュメ末尾に、その回で何にAIを使ったかを記載します。

デザインと技術の関係を論じる講義で、講師だけが自分の制作プロセスを見せないというのは筋が通りません。皆さんに申告を求める以上、こちらも開示します。
