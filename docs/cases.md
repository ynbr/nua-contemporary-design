# 事例集

この講義は理論の話が続きます。ただ、**実物を見れば一瞬で分かる**ことも多い。ここには、講義で触れるプロジェクトの公式ページを集めています。写真も映像もリンク先にあります。

気になったものから開いてください。期末レポートで扱う事例を探すときの出発点にも使えます。

## 厄介な問題を扱う

**[Forensic Architecture — Airstrikes on Minab](https://forensic-architecture.org/investigation/airstrikes-on-minab)**
: ロンドン大学ゴールドスミス・カレッジ（Goldsmiths, University of London）に拠点を置く研究グループ。建築と空間解析の手法を使って、空爆・国家暴力・環境破壊を映像や衛星画像から再構成し、**法廷や人権機関に提出できる証拠**をつくります。「Airstrikes on Minab」はその調査のひとつ。
: つくることと調べることの境目が消える場所です。第1回で扱った**デザインによる研究（research through design）**の、もっとも極端な実例のひとつだと思います。（第1回・第7回・第9回）
: 日本語で読む — [人権をテーマにしたリサーチエージェンシーForensic Architectureが、建築を通じて真実を追究する理由](https://www.axismag.jp/posts/2019/03/121040.html)（AXIS、2019年）／[催涙弾のデジタルモデルを構築して画像検知が可能に](https://www.axismag.jp/posts/2019/05/128940.html)（AXIS、2019年）

**[Superflux](https://superflux.in/index.php/work/)**
: 気候危機や技術のゆくえを、体験できる空間や映像として立ち上げるロンドンのスタジオ。（第10回・第12回）

## 素材はどこから来るのか

**[Studio Swine — Hair Highway](https://studioswine.com/work/hair-highway/)**
: 人間の髪の毛を素材として捉え直すプロジェクト。人口が増えれば髪も増えます。べっ甲や熱帯の木材のように枯渇していく資源の代わりに、**増え続ける資源としての人毛**を使う。中国は世界最大の人毛の産地です。シルクロードが絹だけでなく技術と美意識も運んだことになぞらえて、清朝と1920年代上海のアール・デコを参照した器物がつくられています。
: 「この素材はどこから来たのか」という問いが、そのままデザインの問いになる例です。（第2回・第5回・第10回）
: 日本語で読む — [＃1 Studio Swine エフェメラルの錬金術 ――儚き素材に新たな美しさを与える](https://www.axismag.jp/posts/2025/09/674391.html)（AXIS、2025年）

**[Christien Meindertsma — PIG 05049](https://www.christienmeindertsma.com/PIG-05049)**
: 「05049」という番号の豚一頭が、最終的にどれだけの種類の製品になったのかを追跡した仕事。（第12回）

**[Formafantasma — Cambio](https://formafantasma.com/work/cambio)**
: 木材産業の統治（ガバナンス）を調べた展示。デザインスタジオが産業構造そのものを調査対象にしています。（第12回）
: 日本語で読む — [木材産業の過去と現在を考察する展覧会「Formafantasma: Cambio」がロンドンで開催](https://www.axismag.jp/posts/2020/03/180792.html)（AXIS、2020年）

## 人間だけを中心に置かない

**[Formafantasma — Oltre Terra](https://formafantasma.com/work/oltre-terra)**
: 羊毛の採取と生産をめぐる歴史・生態・グローバルな力学を追った調査。2023年、オスロ国立美術館（Nasjonalmuseet）での展示という形をとっています。**人間以外の生きものとともに設計する（more-than-human design）**という考え方の代表例。羊と人間の長い関係を扱う点では、第2回の工芸と産業の話とも重なります。（第12回・第13回）
: 日本語で読む — [フォルマファンタズマ、サーペンタイン・ギャラリーの生態学分野・主任研究開発フェローに就任](https://www.axismag.jp/posts/2026/08/719165.html)（AXIS、2026年）

**[Cooking Sections — CLIMAVORE: On Tidal Zones](https://www.cooking-sections.com/CLIMAVORE-On-Tidal-Zones)**
: 「気候危機の時代に何を食べるか」を問う、2017年から続くインスタレーション兼パフォーマンス。春夏秋冬でも乾季・雨季でもなく、**地盤沈下・鉄砲水・干ばつといった人為的な気候現象に合わせた「季節」**を立てます。肉食・雑食・地産地消・菜食とは別の食べ方として CLIMAVORE を提案する。
: 単一の世界を前提にしないデザイン（pluriversal design）、移行のデザイン（transition design）の文脈で参照されます。（第12回・第13回）
: 日本語で読む — [乾燥した環境でも育つ砂漠植物について考える Cooking Sectionsのインスタレーション「Becoming Xerophile」](https://www.axismag.jp/posts/2020/02/171351.html)（AXIS、2020年）

## 誰のためのデザインかを問う

**[Design Justice Network](https://designjustice.org/)**
: デザインが誰を利し、誰を締め出すのかを問うネットワーク。原則（Design Justice Principles）が公開されています。（第11回）

**[木原共 — Street Debater](https://www.tomokihara.com/ja/street-debater.html)**
: 路上生活者が、ものごい以外の方法で尊厳を失わずに収入を得るための「仕事」として考案された道具。質問を書いたボードと天秤を使い、通行人がどちらかの皿に硬貨を投じると、その傾きで世論が見えるようになります。デルフト工科大学院での調査から始まりました。（第2回・第9回・第11回）
: 「支援する人」と「される人」という関係そのものを、道具のかたちで組み替えた例です。**解くべき問題を貧困の解消ではなく、尊厳と対話の側に置き直している**ところを見てください。

## つくる人と、かたちを決める人をつなぎ直す

19世紀に分かれた二つの役割を、もう一度つなごうとしている実践です。**国ではなく、分離のどこを埋め戻そうとしているかで三つに分けています。**（第2回）

どれも、モリスが解けなかった「手をかければ高くなる」という問題を抱えたまま進んでいます。

### 型A　工程を見せる

分離の問題を「つくる過程が見えなくなったこと」と捉える立場。19世紀の万国博覧会と意匠改革の系譜にあたります。

**[燕三条 工場の祭典](https://kouba-fes.jp/)**（新潟）
: 金属加工の町工場が、数日間いっせいに扉を開けるイベント。分業によって見えなくなった工程を、見える場所に戻します。産地のブランド化と若手の雇用につながりました。
: 「工場を見せる」こと自体がデザインの対象になっている例です。

**[フォルマファンタズマ（Formafantasma）](https://formafantasma.com/)**（イタリア／オランダ）
: 製品ではなく産業そのものを調査の対象にするスタジオ。[カンビオ（Cambio）](https://formafantasma.com/work/cambio)（2020年、サーペンタイン・ギャラリーズ）では、木材産業が誰にどう統治されているかを追いかけ、いまの木材取引が19世紀の植民地での資源調査から広がったことまで遡ります。
: 設計する前に、自分が使う素材の来歴を調べるという仕事のしかた。第12回（トランジションデザインと環境危機）にもつながります。

### 型B　決定権と対価を戻す

分離の問題を「判断を奪われたこと」と捉える立場。ラスキンとモリスの系譜にあたります。

**ジャイプール・ラグズ（Jaipur Rugs、インド）**
: 四万人を超える地方の織り手と直接取引し、中間業者を挟まない仕組みをつくった手織り絨毯のブランド。[マンチャハ（Manchaha）](https://www.jaipurrugs.com/manchaha)では織り手に図案を渡さず、記憶や情景をもとに織り機の上で文様をその場で決めさせます。賃金と意思決定の両方を、つくる側に戻す試みです。
: [フリーダム・マンチャハ（Freedom Manchaha）](https://www.jaipurrugs.com/collections/freedom-manchaha)では、ジャイプール、ビーカーネール、ダウサの刑務所で長期刑の受刑者が織ります。材料は製造工程で出た残り糸。決める余地をいちばん持たされていない人に、決める役が回っている例です。

**[カマロアン（Kamaro'an）](https://www.kamaroan.com/posts/about)**（台湾）
: 2013年から、台湾東海岸の先住民族パンツァハ（Pangcah、行政上は阿美族＝アミ族と呼ばれる）の編みの技術と植物素材を使って、照明やかばんをつくるブランド。団体名は彼らの言葉で「住むための場所」という意味です。技術を「保存」するのではなく、買われ続ける製品にして残すという選び方です。
: 第13回（脱植民地デザインと多様なデザイン史）でもう一度扱います。

**[GO ON](https://www.go-on-project.com/projects/)**（京都）
: 西陣織、茶筒、金網など、京都の工芸の若手後継者が集まったユニット。家業を継ぐだけでなく、GO ON × Panasonic Design のような家電メーカーとの共同開発や、京都市京セラ美術館での展覧会「Visionaries: Making Another Perspective」を自分たちで仕掛けています。
: 発注を待つ側から、何をつくるかを決める側へ回った例です。

**[中川政七商店](https://www.nakagawa-masashichi.jp/)**（奈良）
: 麻織物の商家から始まり、いまは各地の工芸メーカーの経営を支える側にも回っています。後継者の問題を、美意識ではなく事業の問題として扱うところが特徴です。

### 型C　質の基準を、工業生産の側に置く

分離を前提として引き受ける立場。手仕事の側にしか美を認めないという前提のほうを外します。柳宗理の延長にあたります。

**無名になるかどうかは結果であって、条件ではありません。** 下の四つのうち後の二つは、設計者の名前を前面に出しています。

**[Found MUJI](https://foundmuji.muji.com/)**（無印良品）
: 世界各地で使われてきた日用品を探し、いまの生活と生産の条件に合わせてつくり直します。民藝が「見つけて集めた」ところを、つくり直して流通に乗せるところまでやります。

**[Super Normal（スーパーノーマル）](https://jaspermorrison.com/exhibitions/2000-2009/super-normal)**
: 2006年、深澤直人とジャスパー・モリソンが東京のAXISギャラリーで開いた展覧会。名前のある製品とない製品を同じ棚に並べました。
: モリソンによれば、問題は誰が設計したかではなく、あるものが複数の点でどれだけ得点できるか。見た目に重きを置きすぎるというデザイナーの罠を避けるための枠組みです。

**[ヘラ・ヨンゲリウス（Hella Jongerius）](https://jongeriuslab.com/)**（オランダ）
: 量産される製品に、あえて一点ごとの違いを戻すデザイナー。[B-Set](https://jongeriuslab.com/work/b-set)（1997年、ロイヤル・ティヘラール・マッカム社）は、磁器をわざと高すぎる温度で焼いて歪ませた食器です。均一であることが機械の美点だという前提を、生産の内側から崩しています。

**[カリモクニュースタンダード](https://www.karimoku-newstandard.jp/)**（愛知）
: 紙の原料にしかならなかった広葉樹の細い木を、機械加工と手作業を組み合わせて家具にしています。手仕事か機械かではなく、両方を使って素材の条件を変える解き方です。
